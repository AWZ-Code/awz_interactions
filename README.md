AWZ Interactions is a RedM script designed to make the game world more immersive and interactive by allowing players to use chairs, benches, beds, pianos, baths, and other environmental objects with realistic RDR2-style scenarios.

The resource includes a clean western-style NUI interaction menu, fully configurable and easy to translate. One of its main features is the scenario preview system: when players browse the available interactions, the script displays a local clone preview of the character performing the selected scenario before the real interaction starts. This allows players to see exactly how the animation will look before confirming it.

**Main features:**

- Western-style NUI interaction menu
- Supports chairs, benches, beds, pianos, baths, and more
- Scenario preview system using a local character clone
- The real player remains visible during preview
- Different scenarios depending on the object type
- Male, female, and adult compatibility checks for scenarios
- Support for a large number of environmental props
- Configurable interaction key
- Customizable UI theme from config.lua
- Multi-language system included
- Easy to translate and expand
- Optional configurable effects, such as character cleaning after bathing
- Clean, immersive, and roleplay-friendly system

*Perfect for roleplay servers that want to improve immersion in towns, saloons, camps, houses, and interiors by giving players more ways to interact naturally with the world around them.*
